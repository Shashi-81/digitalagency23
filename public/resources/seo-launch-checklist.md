# SEO Launch Checklist

## Technical

- [ ] Set one canonical URL per page.
- [ ] Add a unique title and description.
- [ ] Confirm robots.txt and sitemap output.
- [ ] Check redirects and 404 handling.
- [ ] Compress images and define dimensions.
- [ ] Test Core Web Vitals on representative pages.

## Content

- [ ] Use one clear H1 per page.
- [ ] Match page copy to search intent.
- [ ] Add descriptive link text.
- [ ] Review internal links and breadcrumbs.
- [ ] Remove placeholder claims and duplicate copy.

## Release

- [ ] Test metadata in social previews.
- [ ] Crawl the production URL.
- [ ] Verify forms, analytics, and conversion events.
- [ ] Monitor search console coverage after launch.

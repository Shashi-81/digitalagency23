# Gipsm Technology UI Kit Starter

## Core screens

- Landing page
- Service detail page
- Case study page
- Contact and qualification flow

## Interface checklist

- Define type scale before styling individual components.
- Use one primary action per viewport.
- Keep spacing tokens consistent across sections.
- Test every important flow on mobile.
- Check contrast, focus states, loading states, and empty states.

## Suggested tokens

- Display: expressive, high-contrast heading face
- Body: readable sans-serif
- Radius: 8px or less for compact controls
- Primary action: one clear accent color
- Surface: use borders and texture to separate regions without nesting cards
